# Portfolio Assets

Drop your personal files into these folders. Each file is served at the matching URL
(anything in `public/` is served at the site root, so `assets/profile/photo.jpg`
is available at `/assets/profile/photo.jpg`).

## profile/

Add your profile photo here. Use the filename `photo.jpg` (or `photo.png`).

> URL expected by the site: `/assets/profile/photo.jpg`
>
> Tip: A square or 4:5 portrait crop between 600–1200px wide looks best.
> Until you add a photo, the site automatically shows a clean monogram avatar,
> so nothing breaks if the folder is empty.

## resume/

Your downloadable resume. Keep it named `PrashantKumar.pdf`

> URL expected by the site: `/assets/resume/PrashantKumar.pdf`

## projects/

Optional screenshots/previews for projects. Recommended names:

- `pulsetalk.png` or `pulsetalk.jpg`
- `intelliwear.png` or `intelliwear.jpg`

> The projects page shows an elegant placeholder (initials + tech stack) whenever a
> screenshot is missing, so the section always looks complete.

---

After dropping your files, they will be picked up automatically — no code changes required.
